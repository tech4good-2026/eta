# Kakao 앱 등록용 아이콘 디자인

## 목적

카카오 Developers의 `Tech4Good Navigation` 앱을 개인 개발자 비즈 앱으로 전환하기 위해 필요한 앱 아이콘을 제작한다. 아이콘은 카카오 콘솔 등록용이며 프론트엔드 화면 디자인이나 브랜드 시스템에는 영향을 주지 않는다.

## 디자인

- 1:1 정사각형의 단순한 플랫 아이콘으로 제작한다.
- 파란색과 민트색을 주조색으로 사용한다.
- 지도 핀, 이동 경로, 작은 시계 요소를 하나의 명확한 심볼로 조합한다.
- 특정 장애 유형이나 이동 보조기구를 직접 묘사하지 않아 전체 교통약자를 포괄한다.
- 작은 크기에서도 식별되도록 요소 수와 선을 최소화한다.
- 텍스트, 상표, 워터마크, 사진 질감, 복잡한 배경은 사용하지 않는다.

## 산출물

- 파일 형식: PNG
- 최종 크기: 128×128px
- 파일 크기: 250KB 이하
- 저장 경로: `assets/tech4good-kakao-icon.png`

## 검증

- 이미지가 정확히 128×128px인지 확인한다.
- PNG 형식이고 250KB 이하인지 확인한다.
- 카카오 Developers 앱 아이콘으로 업로드되는지 확인한다.
- 업로드 후 비즈 앱 전환 단계가 활성화되는지 확인한다.
