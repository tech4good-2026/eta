## 수치 해석

빈 캐시 8개 → 원본 1번, 채운 캐시 8개 → 원본 추가 0번은 테스트 대역을 사용하는 로컬 요청 수 관측입니다. 실제 API 응답시간이나 길찾기 정확도를 뜻하지 않습니다. 재현은 `tests/test_rebuild_boundaries.py`와 `PYTHONPATH=. uv run python tools/measure_source_cache.py`입니다. [원표본·조건·소스 해시](evidence/2026-10-02/source-cache.json), [테스트 결과](evidence/2026-10-02/tests.xml)를 보관했습니다.

기존 `docs/PERF_RESULT.md`는 호출당 고정 50ms와 중복 후보를 넣은 함수 실험입니다. 실제 서울 API 또는 HTTP 서버의 성능 측정으로 소개하지 않습니다.

## 남은 범위

실 API 자격 증명·실제 지도·현장 경로·운행 상태·여러 worker 간 캐시 공유·운영 장애 대응은 미검증입니다. 기존 의존성의 npm 감사 경고는 일괄 업데이트하지 않았습니다. 새 기본 인증 시스템이나 지도 기능 확장은 이번 보강에 포함하지 않습니다.

## 공개 전 CI 보강

GitHub UTC 환경에서 기존 완료 응답 테스트가 `Z`와 `+00:00`을 문자열로 비교해 실패했습니다. 로컬 `TZ=UTC`로 같은 실패를 재현했고, 시간은 같은 순간인지 파싱해 비교하며 나머지 응답 필드·중복 완료 거절 검증은 유지했습니다. 수정 후 UTC 전체 83개와 Asia/Seoul의 해당 회귀를 확인합니다.
